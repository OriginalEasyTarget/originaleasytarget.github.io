Railway building · 2 to 4 players

Ensen 沿線

Run a private railway across Japan. Lay track and grow the towns around your stations. Play on one screen passed around the table, or start an online room and share the code with friends.

  • 2–4 players
  • 60–90 min
  • Same couch or online
  • Saves as you go

There are some rules to learn, so the first game takes a while.

Find the treasure in a dark maze with only a flashlight, and watch out for monsters. You can set the maze size, the beam length and the number of monsters.
